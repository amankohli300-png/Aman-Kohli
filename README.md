## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Once the deployment completes, open: https://amankohli300-png.github.io/Aman-Kohli/

This site uses static HTML, CSS and JavaScript. Check all contact links and forms before using the site for live business enquiries.
